# ADR-0010 – Estratégia de MVP vs Produto Comercial

## Status
Aceito

## Contexto
É necessário entregar valor rapidamente (MVP), sem comprometer a evolução para produto enterprise.

## Decisão
Dividir roadmap em fases:

### MVP
- Cadastro de usuários e câmeras
- Ingestão RTSP
- Gravação contínua
- Playback via HLS
- Detecção de movimento básica

### Produto Comercial
- IA avançada (faces, placas)
- WebRTC
- GPU acceleration
- Multi-storage
- Licenciamento e billing

## Consequências
- Time-to-market rápido
- Base sólida para escalar
